# Standup

## Overview

Скилл собирает коммиты за вчерашний календарный день и формирует детальный отчёт для
стендапа: не просто список заголовков коммитов, а что именно было сделано, зачем и в
каких частях монорепо (`frontend` / `backend` / `packages/database`).

Работает только в текущем git-репозитории (`todo_learn`). Разрешены только
bash-команды `git *` и `date *` — этого достаточно, дополнительные инструменты не
нужны.

## Часовой пояс — всегда московское время (MSK, UTC+3)

**Все даты и время в этом скилле считаются по московскому времени (`Europe/Moscow`,
UTC+3), а не по локальному времени сервера.** Сервер живёт в другом часовом поясе
(`Europe/Amsterdam`, UTC+2), поэтому «вчера» по локальному времени и «вчера» по Москве
не совпадают: коммиты, сделанные между 23:00 и 00:00 по MSK, по серверному времени
попадают в предыдущий день.

Отсюда правила:

- Никогда не использовать `date` и `git log` без явного `TZ=Europe/Moscow`.
- Не использовать относительные границы `--since="yesterday"` / `--until="today"` —
  git интерпретирует их по локальному времени сервера. Границы задавать явными
  датами со смещением `+0300`.
- Время коммитов в отчёте (`HH:MM`) выводить в MSK.

## Порядок действий

1. Вычислить вчерашнюю и сегодняшнюю даты по Москве:

   ```bash
   TZ=Europe/Moscow date +%F            # сегодня по MSK
   TZ=Europe/Moscow date -d yesterday +%F   # вчера по MSK
   ```

2. Взять коммиты за вчера, задав границы суток явно в MSK (`+0300`):

   ```bash
   git log --since="<YESTERDAY> 00:00:00 +0300" \
           --until="<TODAY> 00:00:00 +0300" \
           --date=format-local:'%H:%M' \
           --pretty=format:'%h %ad %s'
   ```

   Здесь `<YESTERDAY>` и `<TODAY>` — даты из шага 1. Чтобы `format-local` отдал
   московское время, команду запускать с `TZ=Europe/Moscow`.

3. Для каждого коммита получить детали через `git show`
4. Сформировать связный текст: что было сделано, в каких модулях
5. Вывести отчёт в формате: «Вчера занимался X, Y, Z»


## Пример вывода
Вчера занимался документированием проекта:
- подключил Swagger, все API-эндпоинты доступны в браузере
- покрыл декораторами все контроллеры модуля транзакций
- добавил JSDoc ко всем публичным методам
- удалил заглушки AppController/AppService
- написал README с инструкцией запуска
- добавил скилл для автоматических коммитов

## Стендап — <YESTERDAY>

### Backend
- **<scope>**: <что сделано и зачем, 1-3 предложения на основе тела коммита/диффа>
  (`<hash>`, <HH:MM>)

### Frontend
- ...

### Прочее
- ...
```

Кратко — без воды, но детально: если коммит фиксил конкретный баг, описать сам баг
и как исправлен; если это фича — что добавлено и какие файлы/модули затронуты.
Не пересказывать заголовок коммита дословно — раскрывать его.
